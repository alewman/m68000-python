# Security policy

`m68000-python` is a pure-Python instruction core. It does not operate a
network service, process credentials, or bundle untrusted machine images.

Please report ordinary correctness defects through GitHub Issues. If a
report would expose a security-sensitive downstream integration problem,
use GitHub's private vulnerability-reporting feature if it is enabled for
the repository, or contact the maintainer privately through GitHub.

The project makes no security certification claim. Consumers remain
responsible for safely handling untrusted ROMs, disk images, data and
host-device code.
